    Dieses Gerät

    Bearbeiten lässt sich nur die Karte dieser Person. Alle anderen Karten sind hier nur zum Ansehen.
    So erstellst du einen Token
    1. Auf GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.
    2. Repository access: Only select repositories, das Länderatlas-Repo wählen.
    3. Permissions → Repository permissions → Contents: Read and write.
    4. Token erzeugen, kopieren und hier einfügen. Er bleibt nur in diesem Browser gespeichert.

    Demo-Modus: Ein Token ist nicht nötig. „Speichern“ legt die Änderungen in diesem Browser ab.

    Daten deiner Karte

    Text kopieren, um eine Sicherung anzulegen. Eingefügter Text ersetzt deine Markierungen; übernommen wird er erst mit „Speichern“. Exporte aus dem Prototyp 0.1 funktionieren ebenfalls.
